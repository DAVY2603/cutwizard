# KENI CutWizard — déploiement GitHub Pages

Ce dossier contient les fichiers statiques prêts à être publiés sur `https://davy2603.github.io/cutwizard/`.

## Instructions de publication

1. Créez (ou utilisez) le dépôt GitHub `cutwizard`.
2. Poussez ce dossier (déjà initialisé en dépôt Git local) vers la branche `main` du dépôt distant :
   ```
   git remote add origin https://github.com/davy2603/cutwizard.git
   git push -u origin main --force
   ```
3. Dans les paramètres du dépôt GitHub → Pages, sélectionnez la branche `main` (dossier racine `/`) comme source.
4. Le site sera disponible sous quelques minutes à `https://davy2603.github.io/cutwizard/`.
